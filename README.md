**Fabric Project using DataFlow Gen2**


**HR Attrition Analysis (IBM Dataset)**

**Tech Stack used**:Microsoft Fabric, Power BI
A dynamic data visualization tool built to explore the employee attrition 

**Short Description/Purpose**
The HR attrition dashboard is a visually engaging and analytical Power BI report designed to help users compare the attrition across 1470 employess.
The dashboard mainly gives the overview of the attrition and deepdive across age-group, salary-bands,by department etc 
**Tech Stack**
The dashboard is built using the following tools and technologies:
Power BI desktop, Power Query, DAX, Data Modelling
MS fabric for ETL process using dataflow gen2 and then loaded to Lakehouse

- This project has helped me understand the end-to-end ETL process using Fabric and governance on one lake security layer (eg:Creating column security on salary column)
